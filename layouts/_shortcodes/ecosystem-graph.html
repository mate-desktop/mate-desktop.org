Every MATE package and how they depend on each other, extracted automatically from each repository's build files.

How to read it

Packages are grouped in bands: applications, applets and extensions at the top, the core desktop in the middle and the libraries everything builds on at the bottom. Arrows point to dependencies; dashed edges are optional.

Select a package to see what it depends on (orange), what depends on it (blue), and open its API reference.
